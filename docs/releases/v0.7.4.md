# agentcli v0.7.4

[English](v0.7.4.md) | [한국어](v0.7.4.ko.md)

Patch release: two debug-observability fixes — no API changes, no behavior
changes outside `debug=True` paths.

## Install

GitHub-first release:

```bash
pip install "agentcli-py @ git+https://github.com/saintiron82/agentcli.git@v0.7.4"
```

## Fixed

- **Aborting a debug stream no longer loses the trace (issue #46).** The
  streaming template's stderr-drain cleanup caught only `Exception`, but
  `CancelledError` is a `BaseException` — and the `finally` site awaits a
  task it just cancelled, making `CancelledError` that await's normal
  outcome. When it leaked, it replaced the in-flight `GeneratorExit`
  (direct consumers: `aclose()` raised; `stream_async` wrappers: an
  asyncgen-finalizer warning) and aborted the remaining cleanup, silently
  dropping the debug trace record. Both sites now share the stdin-task
  contract from #44.

- **codex prompts are now redacted from debug traces (issue #42).**
  `redact_argv` only knew claude's `-p <prompt>` form; a codex prompt
  rides as the last positional after the `--` terminator and landed in
  `debug_log_path` traces in full. It is now replaced with the usual
  `<prompt:N chars>` marker. The stdin placeholder (`-`) is preserved so
  traces still show stdin routing, and the resume session id stays
  visible. copilot's `-p` form was measured as already covered and is now
  pinned by a regression test.

## Notes

If you attach `debug_log_path` traces to bug reports, upgrade before
capturing codex traces — pre-0.7.4 traces contain the full prompt text.
