# agentcli v0.7.6

[English](https://github.com/saintiron82/agentcli/blob/v0.7.6/docs/releases/v0.7.6.md) | [한국어](https://github.com/saintiron82/agentcli/blob/v0.7.6/docs/releases/v0.7.6.ko.md)

릴리스 날짜: 2026-10-22. v0.7.5 이후의 보안 보강, 서비스별 독립 인증,
세션·동시성 개선과 CLI 실패 응답 수정을 포함합니다.

## 설치

```bash
python -m pip install --upgrade "agentcli-py @ git+https://github.com/saintiron82/agentcli.git@v0.7.6"
```

GitHub Release에 `agentcli_py-0.7.6-py3-none-any.whl`과 소스 패키지를 제공합니다.
Python 3.11+와 별도로 설치·인증한 provider CLI가 필요하며 런타임 의존성은
없습니다. GitHub 게시가 PyPI 게시를 의미하지는 않으며, PyPI는 기존 저장소의
명시적 활성화 설정으로 제어합니다.

## 수정

- Claude 프롬프트를 모든 옵션과 `--` 뒤에 배치하여 `--version`, `--help`,
  하이픈으로 시작하는 입력을 사용자 텍스트로 전달합니다. 긴 프롬프트의
  stdin·EOF 처리는 유지합니다 (이슈 #82).
- Claude/Codex 동기·비동기 호출은 종료 코드가 0이 아니어도 stdout의 오류와
  사용량을 보존합니다. Claude 숫자형 HTTP 429는 `usage_limit`으로 분류하며
  stderr와 실제 종료 코드도 유지합니다 (이슈 #81).
- 취소·조기 종료 시 스트림이 소유한 generator·프로세스를 정리합니다.
  일부 텍스트 뒤에 오류가 나면 실패로 반환하며 오류 청크의 세션·사용량을 보존합니다.
- 취소되어도 worker가 끝날 때까지 세션 lease를 유지합니다. 진행·대기 중인
  세션의 퇴거·초기화 경합을 막고 클라이언트·호출 모드·로컬 SQLite 프로세스
  사이에서 같은 세션의 작업을 조정합니다.
- 파일 배치 시 사용자 스킬을 보존하고 겹치는 스킬 트리와 내부 링크를 거부하며,
  macOS의 신뢰한 작업 루트 별칭을 처리합니다.
- Codex 인사말·만료 세션 복구의 시도 횟수와 사용량 집계를 통일합니다.
  재시도 전체에 wall 예산을 공유하며 SQLite 통계는 사용량 행 전체를 읽는 대신
  일관된 스냅샷에서 집계합니다.

## 추가·보강

- `AuthProfile`로 서비스별 인증과 네이티브 CLI 경로를 client에 연결합니다.
  교체·비활성화는 이후 호출에 적용하고 진행 중 호출은 인증 스냅샷을 유지합니다.
  [서비스 인증 문서](https://github.com/saintiron82/agentcli/blob/v0.7.6/docs/service-auth.ko.md)를 보십시오.
- 대화의 owner·workspace 경계를 검사합니다. 다른 owner의 컨텍스트는 호스트
  승인이 필요하며 미지원·비호환 보안 정책은 차단합니다.
- Windows npm shim의 해석기를 직접 실행하고 알 수 없는 wrapper는 거부합니다.
  자동 진단에서 민감한 본문을 제외합니다 (trace schema 2).
- Kiro 파일 읽기·쓰기 권한을 명시하고 파일 크기는 기본 1 MiB로 제한합니다.

## 업그레이드·운영 경계

보안 검사가 강화되어 이전에 허용하던 호출이 거부될 수 있습니다. 같은 owner와
정규화한 workspace를 유지하고 지원하는 provider 옵션을 전달하십시오. Codex
세션의 실행 정책을 바꿀 때는 `new_session=True`가 필요합니다. Claude 기본
`env="explicit"`은 `fallback=True`여도 동등한 정책이 확인되지 않은 다른
native provider로 전환하지 않습니다.

인증 프로필은 선택 기능이며 기존 client는 이행 전까지 공유 인증을 유지합니다.
Kiro 프로필 인증은 미지원입니다. owner는 인증이 아니며 같은 OS 사용자로 실행한
악성 코드를 프로필로 격리할 수는 없습니다. 다중 서버 writer는 호스트 조정이
필요합니다. 도구의 외부 변경은 rollback하지 않으며 정리·lease 대기 시간은
실행 예산을 넘을 수 있습니다.

계정 한도 조회와 로컬 사용량 통계는 별개입니다. 리셋 쿠폰 조회·사용이나 공개
비용·HTTP 상태 필드는 추가하지 않습니다. 오프라인 회귀 테스트가 실제 인증과
provider 엔드포인트의 동작까지 보장하지는 않습니다.
[운영 지침](https://github.com/saintiron82/agentcli/blob/v0.7.6/docs/operations.ko.md)에서
서비스 적용 전 확인 사항을 보십시오.
