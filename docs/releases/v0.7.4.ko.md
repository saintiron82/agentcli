## Fixed

- **debug 스트림 중도 중단 시 trace 가 유실되지 않는다 (issue #46).**
  스트리밍 템플릿의 stderr 드레인 정리가 `Exception` 만 잡았는데,
  `CancelledError` 는 `BaseException` 이다 — 게다가 `finally` 쪽은 방금
  자기가 cancel() 한 task 를 await 하므로 `CancelledError` 가 그 await 의
  *정상* 결과다. 이것이 새면 진행 중인 `GeneratorExit` 를 대체하고(직접
  소비자: `aclose()` 가 예외로 종료; `stream_async` 래퍼: asyncgen
  파이널라이저 경고) 나머지 정리가 중단되어 debug trace 기록이 조용히
  사라졌다. 두 지점 모두 #44 의 stdin_task 계약을 따르도록 수정.

- **codex 프롬프트가 debug trace 에서 가려진다 (issue #42).**
  `redact_argv` 가 claude 의 `-p <prompt>` 형태만 알아서, `--` 종결자 뒤
  마지막 위치 인자로 실리는 codex 프롬프트는 `debug_log_path` trace 에
  전문이 그대로 기록됐다. 이제 통상의 `<prompt:N chars>` 마커로 치환된다.
  stdin placeholder(`-`)는 남겨 stdin 경유임이 trace 에 보이게 하고, resume
  session id 는 진단용으로 유지한다. copilot 의 `-p` 형태는 이미 커버였음을
  실측 확인하고 회귀 테스트로 고정했다.

## Notes

버그 리포트에 `debug_log_path` trace 를 첨부하는 워크플로라면, codex trace
캡처 전에 업그레이드할 것 — 0.7.4 이전 trace 에는 프롬프트 전문이 담겨 있다.
