# agentcli v0.7.5

[English](https://github.com/saintiron82/agentcli/blob/v0.7.5/docs/releases/v0.7.5.md) | [한국어](https://github.com/saintiron82/agentcli/blob/v0.7.5/docs/releases/v0.7.5.ko.md)

릴리스 날짜: 2026-10-12. v0.7.4 이후의 계정 한도 조회, 구조화 출력,
최신 Codex CLI 호환성 수정을 묶은 릴리스다.

## 설치

Git이 설치된 환경에서 태그 소스로 설치한다:

```bash
python -m pip install --upgrade "agentcli-py @ git+https://github.com/saintiron82/agentcli.git@v0.7.5"
```

GitHub Release에 첨부된 `agentcli_py-0.7.5-py3-none-any.whl`로도 설치할 수 있다.
wheel에는 라이브러리만 포함되며 provider CLI 실행 파일이나 인증 정보는 없다.
Python 3.11+와 별도로 설치·인증한 provider CLI가 필요하다.
GitHub 게시가 같은 버전의 PyPI 게시를 의미하지는 않는다.

## 추가

- `get_account_usage()`와 `get_account_usage_async()`가 Claude/Codex 구독의
  사용률·초기화 시간을 `AccountUsage`, `UsageWindow` 공통 형식으로 반환한다.
  `client.supports(provider, "account_usage")`로 지원 여부를 확인한다.
- Claude 브라우저 OAuth와 Codex ChatGPT OAuth는 GET으로 사용량을 조회한다.
  Claude setup-token의 추론 요청은 `allow_probe=True`일 때만 허용하며,
  `max_tokens=1`은 출력 상한이지 총 소비량이 아니다. 인증 정보는 갱신하거나
  덮어쓰지 않는다.
- `chat` / `chat_async`의 `output_schema`, `validator`, `schema_retries`로
  구조화 출력을 검증한다. 검증 결과는 `response.parsed`로 반환하며,
  재시도 후에도 검증이 실패하면 구조화된 schema 오류를 반환한다 (issue #72).
- 한·영 계정 사용량 매뉴얼과 여러 에이전트를 조율하는 coordinator-loop
  cookbook 예제를 추가했다.

## 수정

- Codex 승인 정책을 삭제된 `-a` 플래그 대신 `-c approval_policy=...`로
  전달한다 (issue #74).
- `full_auto` 인자는 하위 호환용으로 유지하되 삭제된 `--full-auto` 플래그는
  출력하지 않아 codex-cli 0.149+ 호환성을 복구했다 (issue #76).
- 잘못된 reasoning 기본값은 provider 생성 시 거부하고, 빈 문자열 처리를
  일관되게 정규화했다 (issue #38 후속 수정).

## 배포 동작과 범위

GitHub Release는 테스트·빌드 성공에 의존하며 PyPI 게시 성공에는 의존하지 않는다.
PyPI 게시에는 repository variable `PYPI_PUBLISH_ENABLED=true`와
Trusted Publisher 설정이 필요하며, 기본적으로 비활성화되어 있다.

계정 한도 조회와 로컬 토큰 통계는 별개다. 누락된 한도는 미확인이며 조회 성공이
잔여 한도를 보장하지는 않는다. API-key 과금 통계, Copilot/Kiro 한도 조회,
키체인 전용 인증 정보 자동 탐색은 지원하지 않는다. 계정 사용량 회귀 테스트는
가짜 인증 정보와 로컬 HTTP 응답을 사용하므로 실제 계정 엔드포인트의 동작까지
검증한 것은 아니다.
